OPTION 01

Automatic extraction

Upload multiple PDF resumes or select a folder. The system processes them one by one and extracts candidate information automatically.

You can select a folder containing hundreds of PDF resumes.
✎
OPTION 02

Manual entry

Use manual entry when a resume is scanned, image-heavy or cannot be read correctly by the PDF parser.

OPTION 03

Import Excel sheet

Import candidate rows from an .xls or .xlsx workbook. Recognized fields are read when present; blank fields are allowed.

Candidate rows save to database automatically. Matching email or phone values are shown as duplicates.
