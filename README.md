# TVK Course Management

TVK Course Management is a web application for managing courses, trainers, students, allocations, attendance, curriculum, and related institute operations.

## Features

- Trainer Management
- Student Management
- Course Management
- Course Allocation
- Student Allocation
- Trainer Attendance
- Student Attendance
- Course Curriculum
- Dashboard
- Authentication and Authorization

## Tech Stack

- Angular
- Node.js
- Express.js
- MongoDB
